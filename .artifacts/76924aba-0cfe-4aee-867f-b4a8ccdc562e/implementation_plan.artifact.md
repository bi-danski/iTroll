# Hybrid Casting Strategy for iOS (Google Cast + AirPlay)

This plan implements a hybrid casting solution for iOS that supports both Google Cast (Chromecast) and native AirPlay within the existing KMP architecture.

## User Review Required

> [!IMPORTANT]
> **CocoaPods Setup**: This change introduces the `kotlin("native.cocoapods")` plugin. You will need to have CocoaPods installed on your machine (`brew install cocoapods`) and run `./gradlew podInstall` after the changes are applied.

> [!WARNING]
> **iOS Project Changes**: If you have an existing Xcode project, you will need to switch to using the `.xcworkspace` generated by CocoaPods instead of the `.xcodeproj`.
